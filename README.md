# ShiJie Wang · Theory & Systems

个人品牌博客，使用 Astro 构建，面向 GitHub Pages 设计。内容、页面和视觉资产分离管理，构建结果输出到 `dist/`。

## GitHub Pages

1. 将项目推送到自己的 GitHub 仓库。
2. 运行 `npm install` 和 `npm run build` 检查构建。
3. 在仓库设置中打开 Pages，选择 GitHub Actions 部署。
4. 使用仓库中的 `.github/workflows/pages.yml` 完成发布。

主页采用纵向幻灯片式结构，后续可以继续加入 Markdown 文章、双语路由、论文索引、RSS、搜索和外部平台链接。
